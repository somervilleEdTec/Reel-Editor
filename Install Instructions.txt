Install Instructions — Reelwright
=================================

Reelwright is a transcript-driven reel compositor and captioning tool.
It runs locally on your computer. The editor opens in your browser at
http://127.0.0.1:8765/ and does not require an internet connection for
normal use.


IMPORTANT — where is ReelwrightSetup.exe?
-----------------------------------------
ReelwrightSetup.exe is NOT committed into the Git source tree.

It is published as a GitHub Release asset instead:

  https://github.com/somervilleEdTec/Reel-Editor/releases

How it is created:
  - GitHub Actions workflow: .github/workflows/release-windows.yml
  - Trigger: push a tag like v0.1.0, or run "Release Windows Package"
    from the Actions tab
  - Output is attached to that Release (and also kept under dist/ on
    the build machine only; dist/ stays gitignored)

Until a Release exists, install from source using section A below.


----------------------------------------------------------------
A. Install from this repository (developers / until a Release exists)
----------------------------------------------------------------

Use this on Windows, macOS, or Linux while developing or if no
installer Release has been published yet.

1. Prerequisites
   - Python 3.11 or newer
   - ffmpeg and ffprobe on your PATH
     (Windows: you may later place LGPL builds in vendor/ffmpeg/)
   - Git

2. Clone the repository
   git clone https://github.com/somervilleEdTec/Reel-Editor.git
   cd Reel-Editor

3. Install the Python package
   pip install -e ".[dev]"

4. Start the local server
   python -m reelwright.api.server
   (or: python3 -m reelwright.api.server)

5. Open the UI
   - Browser: http://127.0.0.1:8765/
   - Complete first-run setup (FFmpeg check, optional model consent,
     projects folder), then use Home → Editor → Export.

6. Optional CLI (no UI)
   reelwright init video.mp4 -o project.json
   reelwright transcribe project.json
   reelwright export project.json -o master.mp4


----------------------------------------------------------------
B. Windows installer from GitHub Releases (end users)
----------------------------------------------------------------

1. Open the Releases page
     https://github.com/somervilleEdTec/Reel-Editor/releases
2. Open the latest release and download ReelwrightSetup.exe
3. Double-click ReelwrightSetup.exe and follow the wizard
   - Install location (default): %LOCALAPPDATA%\Reelwright
   - No administrator rights are required
   - Optional: create a desktop icon
4. Start Menu → Reelwright
   - Launcher starts http://127.0.0.1:8765/ and opens your browser
5. Complete first-run setup, then create or open a reel


----------------------------------------------------------------
C. Publish a Release / build the installer (maintainers)
----------------------------------------------------------------

Preferred: GitHub Actions (creates the Release + attaches the .exe)

1. Merge packaging changes to main
2. Either:
   a) Tag and push:
        git tag v0.1.0
        git push origin v0.1.0
   b) Or: GitHub → Actions → "Release Windows Package" → Run workflow
      (enter tag e.g. v0.1.0)
3. Wait for the Windows job to finish
4. Confirm the Release under:
     https://github.com/somervilleEdTec/Reel-Editor/releases
   Asset: ReelwrightSetup.exe

Local Windows build (optional):

1. Python 3.11+, Inno Setup 6, then:
     powershell -ExecutionPolicy Bypass -File packaging/windows/build.ps1 -Version 0.1.0 -FetchFfmpeg
2. Output: dist\windows\installer\ReelwrightSetup.exe
   (still do not commit; upload via the Actions release workflow)


----------------------------------------------------------------
D. Optional cloud features (opt-in)
----------------------------------------------------------------

Reelwright works offline by default. Cloud features only run if you
set environment variables for your own Azure subscription:

  AZURE_SPEECH_KEY
  AZURE_SPEECH_REGION
  AZURE_OPENAI_ENDPOINT
  AZURE_OPENAI_API_KEY
  AZURE_OPENAI_DEPLOYMENT

Do not put API keys in the repository.


----------------------------------------------------------------
E. Security notes for local installs
----------------------------------------------------------------

- The API listens on 127.0.0.1 only (this computer), not the network.
- For a stricter workspace lockdown, set REELWRIGHT_ROOT to your
  projects folder before starting the server.
- Related packaging detail: docs/packaging-windows.md
- Licence notes: LICENCE_NOTES.md


----------------------------------------------------------------
F. Uninstall (Windows installer)
----------------------------------------------------------------

1. Open Windows Settings → Apps → Installed apps.
2. Find Reelwright → Uninstall.
3. Your projects folder under %LOCALAPPDATA%\Reelwright\projects
   may remain; delete it manually if you no longer need those files.
