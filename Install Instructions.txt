Install Instructions — Reelwright
=================================

Reelwright is a transcript-driven reel compositor and captioning tool.
It runs locally on your computer. The editor opens in your browser at
http://127.0.0.1:8765/ and does not require an internet connection for
normal use.


IMPORTANT — where is ReelwrightSetup.exe?
-----------------------------------------
ReelwrightSetup.exe is NOT stored in this GitHub repository.

Reasons:
  - It is a large Windows build artifact (PyInstaller + Inno Setup).
  - The dist/ folder is listed in .gitignore on purpose.
  - Binaries must be built on a Windows machine (see section C).

What IS in the repo:
  - Source code
  - packaging/windows/ scripts that CREATE the installer
  - Placeholders under vendor/ffmpeg/ and vendor/models/ (README only)

Until someone builds and shares ReelwrightSetup.exe, install from
source using section A below.


----------------------------------------------------------------
A. Install from this repository (works today)
----------------------------------------------------------------

Use this on Windows, macOS, or Linux while developing or until an
installer build is published.

1. Prerequisites
   - Python 3.11 or newer
   - ffmpeg and ffprobe on your PATH
     (Windows: you may later place LGPL builds in vendor/ffmpeg/)
   - Git

2. Clone the repository
   git clone https://github.com/somervilleEdTec/Reel-Editor.git
   cd Reel-Editor

3. Install the Python package
   pip install -e ".[dev]"

4. Start the local server
   python -m reelwright.api.server
   (or: python3 -m reelwright.api.server)

5. Open the UI
   - Browser: http://127.0.0.1:8765/
   - Complete first-run setup (FFmpeg check, optional model consent,
     projects folder), then use Home → Editor → Export.

6. Optional CLI (no UI)
   reelwright init video.mp4 -o project.json
   reelwright transcribe project.json
   reelwright export project.json -o master.mp4


----------------------------------------------------------------
B. Windows installer (only AFTER it has been built)
----------------------------------------------------------------

Use this only if you already have ReelwrightSetup.exe from a team
release or from a local build (section C). You will not find this
file by browsing the GitHub repo.

1. Get the installer
   - From your school/team distribution, OR
   - From a build output folder:
       dist\windows\installer\ReelwrightSetup.exe
     (created on a Windows PC by packaging/windows/build.ps1)

2. Run the installer
   - Double-click ReelwrightSetup.exe.
   - Follow the on-screen steps.
   - Install location (default): %LOCALAPPDATA%\Reelwright
   - No administrator rights are required.
   - Optional: tick "Create a desktop icon" if offered.

3. Start Reelwright
   - Open Start Menu → Reelwright
     (or the desktop shortcut if you created one).
   - The launcher starts a local API on 127.0.0.1:8765 and opens
     your default browser.

4. Complete first-run setup (in the browser)
   - Confirm FFmpeg is available (bundled vendor copy or system PATH).
   - Optionally consent to download a transcription model
     (you can skip and do this later).
   - Choose a projects folder (default:
     %LOCALAPPDATA%\Reelwright\projects).

5. Create or open a reel
   - From Home, start a new reel or open a recent project.
   - Use the editor to trim words, adjust composition, then Export.


----------------------------------------------------------------
C. Build ReelwrightSetup.exe (maintainers, Windows only)
----------------------------------------------------------------

Run these steps on a Windows machine (or Windows CI runner).
This is how the missing .exe is produced.

1. Install build tools
   - Python 3.11+
   - pip install -e ".[dev]" pyinstaller
   - Inno Setup 6 (https://jrsoftware.org/isinfo.php)
   - Optional: copy LGPL ffmpeg.exe and ffprobe.exe into
     vendor\ffmpeg\ before building (see vendor/ffmpeg/README.md)

2. Build bundle + installer
   powershell -ExecutionPolicy Bypass -File packaging/windows/build.ps1

3. Find the output (still not committed to git)
   - Installer: dist\windows\installer\ReelwrightSetup.exe
   - If Inno Setup is missing, the app bundle is at
     dist\windows\bundle\
   - Distribute that .exe to end users by release download / shared
     drive — do not commit it to the repository.


----------------------------------------------------------------
D. Optional cloud features (opt-in)
----------------------------------------------------------------

Reelwright works offline by default. Cloud features only run if you
set environment variables for your own Azure subscription:

  AZURE_SPEECH_KEY
  AZURE_SPEECH_REGION
  AZURE_OPENAI_ENDPOINT
  AZURE_OPENAI_API_KEY
  AZURE_OPENAI_DEPLOYMENT

Do not put API keys in the repository.


----------------------------------------------------------------
E. Security notes for local installs
----------------------------------------------------------------

- The API listens on 127.0.0.1 only (this computer), not the network.
- For a stricter workspace lockdown, set REELWRIGHT_ROOT to your
  projects folder before starting the server.
- Related packaging detail: docs/packaging-windows.md
- Licence notes: LICENCE_NOTES.md


----------------------------------------------------------------
F. Uninstall (Windows installer)
----------------------------------------------------------------

1. Open Windows Settings → Apps → Installed apps.
2. Find Reelwright → Uninstall.
3. Your projects folder under %LOCALAPPDATA%\Reelwright\projects
   may remain; delete it manually if you no longer need those files.
